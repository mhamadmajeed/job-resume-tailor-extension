FAQ

Questions people ask before installing

Does it invent experience I don't have?

No. Resume Tailor only reframes real experience already in your resume to match the language of the job. Ultra pushes that framing the hardest of the four intensities, but no intensity fabricates skills, jobs, or accomplishments you didn't have.

Which job sites does it work on?

It's built and tested for LinkedIn job pages, where it works best. Other job boards are supported on a best-effort basis, since every site formats its listings differently.

Where is my data stored?

Your resume and job data are stored securely and are only used to generate your tailored resumes.

How do match scores work?

Each score comes from a strict, recruiter-calibrated AI rubric. The same rubric is used before and after tailoring, so the improvement you see reflects a real difference, not a looser second pass.

Do I need Chrome to use it?

Right now Resume Tailor is a Chrome extension, installed from GitHub while the Chrome Web Store listing is in progress. A Chrome Web Store listing is coming soon.
